# yulfolio

황은율 포트폴리오 — 콘텐츠 프로토타입

신한 SOL pay 〈[Tasty SOLution]〉 연재분을 실제 앱 화면 기준으로 재현한 모바일 프로토타입입니다.

## 페이지

| URL | 화면 |
|---|---|
| `/` | 시리즈 목록 (총 106화) |
| `/ep4.html` | 4화 · 집에서 빙수 만들기, 이게 되네? |
| `/ep13.html` | 13화 · 호랑이도 반한 겨울별미, 수수부꾸미 |
| `/ep19.html` | 19화 · 분식 못 잃어! 다이어터를 위한 레시피 |
| `/ep30.html` | 30화 · 여름밤, 홈메이드 막걸리와 함께 |
| `/ep61.html` | 61화 · 잼보다 더 향긋한 시나몬 사과 콩포트 |
| `/ep65.html` | 65화 · 운동할 땐 간식도 건강하게! |

목록에서 4·13·19·30·61·65화를 누르면 해당 상세로 이동합니다.

## 구성

- 아이폰 14 목업 안에서 390×844로 동작하는 정적 페이지
- 이미지는 `assets/img/`에 외부 파일로 두고 지연 로딩 — 첫 로딩 350~580KB
- 폰트(Pretendard, Cabin, Cabin Condensed)는 사용 문자만 서브셋해 `assets/fonts/`에 내장
- 스크롤 시 블러 고정 상단바, 목록 행 눌림 상태 등 실제 앱 인터랙션 재현
